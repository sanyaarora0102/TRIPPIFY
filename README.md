# TRIPPIFY ✈️
TRIPPIFY is a command-line travel recommendation application written in Python. It helps users discover personalized travel destinations, hotel recommendations, sightseeing spots, and packing checklists based on their budget, trip duration, group size, and preferred environment (mountains or beaches).


##  Features
* **Budget-Based Filtering:** Recommends destinations tailored for budgets below or above ₹30,000.
* **Terrain Preference:** Lets users choose between mountain and beach getaways.
* **Personalized Recommendations:** Provides curated lists of hotels and tourist attractions for popular Indian destinations.


##  Technologies / Tools Used
* **Language:** Python 3.14
* **Environment:** Terminal / Command Prompt / Python IDE
